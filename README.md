# Queen's Hidden Match – Landing Page

A progressive landing page for the mobile casual game **"Queen's Hidden Match"** (genres: Hidden Object, Match-3, Puzzle). The website is developed with an emphasis on a premium visual style, smooth animations, and maximum mobile responsiveness.

## 🚀 Technology Stack

* **Programming Language:** Vanilla JavaScript (ES6+)
* **Build Tool:** Vite
* **Styling:** Pure CSS
* **Hosting:** GitHub Pages

---

## 🛠️ Features & Architecture

The project is implemented as a single-page application (with SPA elements) featuring integrated functional sections:
1. **Hero Section:** A Call to Action (CTA) with a link to Google Play, featuring graphics optimized for mobile screens.
2. **About the Game:** A presentation of gameplay highlights (relaxing mode, royal setting).
3. **Advantages:** A visual block showcasing the game's beautifully designed royal environments.
4. **FAQ Accordion:** An interactive "Frequently Asked Questions" section built with pure JS without any third-party libraries.
5. **Legal Pages (Routing):** Fully styled and integrated **Terms of Service** and **Privacy Policy** pages that match the overall design ecosystem of the project.
